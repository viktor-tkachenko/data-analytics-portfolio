# Data Analytics Portfolio

Projects I built while training as a data analyst (Mate academy Data Analyst course), after working as an analytical chemist in a laboratory. Tools: SQL (BigQuery), Python, Tableau, statistics, A/B testing.

**Viktor Tkachenko** · [LinkedIn](https://www.linkedin.com/in/viktor-tkachenko-8b1b782b1)

## Projects

| Project | Tools | What it shows |
|---|---|---|
| [E-commerce Sales Analytics](e-commerce/) | SQL, Python, Tableau | End-to-end analysis of an online store: dataset building, EDA, sales dynamics, conversion, correlations and statistical tests, two-page dashboard |
| [A/B Testing: Statistical Significance](ab-testing/) | SQL, Python, Tableau | Significance of four conversion metrics across four A/B tests (two-proportion z-test) with an interactive dashboard |
| [Exploratory Data Analysis: sales orders](eda-online-store/) | Python | Cleaning and merging three related tables, then analysis of categories, geography, sales channels, shipping time and sales trends |
| [SQL queries](sql/) | SQL (BigQuery) | Four queries with CTEs, window functions and `UNION ALL`: A/B test data preparation, continent metrics, email metrics view, monthly email share |
