# Метрики акаунтів і email-розсилок за країнами

## Задача
Зібрати в BigQuery єдине представлення (view) з показниками акаунтів та email-комунікацій
у розрізі дати, країни й параметрів акаунта, а потім залишити лише
**топ-10 країн** за кількістю акаунтів або за кількістю надісланих листів.

## Що містить результат

| Колонка | Опис |
| 'date' | дата (для листів: дата сесії + 'sent_date') |
| 'country' | країна |
| 'send_interval' | інтервал розсилки, обраний акаунтом |
| 'is_verified' | чи верифікований акаунт |
| 'is_unsubscribed' | чи відписаний від розсилки |
| 'account_cnt' | кількість унікальних акаунтів |
| 'sent_msg' | надіслані листи |
| 'open_msg' | відкриті листи |
| 'visit_msg' | листи, після яких був перехід на сайт |
| 'total_country_account_cnt' / 'total_country_sent_cnt' | підсумки по країні |
| 'rank_total_country_account_cnt' / 'rank_total_country_sent_cnt' | ранг країни за акаунтами / за надісланими листами |

## Як це працює
1. **'acc_metrics'**: кількість акаунтів за вимірами. Метрики листів заповнені нулями, щоб структури збігалися для об'єднання.
2. **'msg_metrics'**: надіслані, відкриті й листи з переходами. 'LEFT JOIN' зберігає листи, які не відкрили й не відвідали.
3. **'final'**: 'UNION ALL' обох наборів і агрегація 'SUM()' за спільними вимірами.
4. **'country_totals'**: загальні підсумки по країні через 'SUM() OVER (PARTITION BY country)'.
5. **'ranked'**: 'DENSE_RANK() OVER (ORDER BY ...)' для ранжування країн. Це зроблено в окремому CTE, бо результат віконної функції не можна фільтрувати в тому самому 'SELECT'.
6. **Фінальний 'SELECT'**: залишає країни з рангом ≤ 10 за будь-яким із двох показників.
7. Результат зберігається як **view** ('CREATE VIEW'), тому його можна підключати до дашбордів.
                                                                                    
## Інструменти й прийоми
- Google BigQuery (GoogleSQL)
- CTE, 'JOIN' / 'LEFT JOIN', 'UNION ALL', 'GROUP BY'
- Віконні функції: 'SUM() OVER', 'DENSE_RANK() OVER'
- 'DATE_ADD', 'COUNT(DISTINCT ...)', 'CREATE VIEW'

## Використані таблиці (схема 'DA')
'account', 'account_session', 'session', 'session_params', 'email_sent', 'email_open', 'email_visit'

## Результат
View став джерелом даних для дашборда **Top 10 Country Statistics**
у Looker Studio (BigQuery → Looker Studio). Дашборд містить:
- стовпчасті діаграми загальної кількості надісланих листів і створених акаунтів по країнах;
- динаміку 'sent_msg', 'open_msg', 'visit_msg' у часі;
- таблиці з рангами країн за акаунтами та за надісланими листами;
- карту (розмір бульбашки: надіслані листи, колір: кількість акаунтів);
- кругові діаграми частки верифікованих і відписаних акаунтів по країнах.
