# Частка листів акаунта від усіх листів місяця

## Задача
Для кожного акаунта визначити, яку частку від усіх листів за місяць він отримав,
а також дати першого й останнього листа в цьому місяці.

## Що містить результат

| Колонка | Опис |
| 'sent_month' | місяць відправлення (перше число місяця) |
| 'id_account' | ідентифікатор акаунта |
| 'sent_msg_percent_from_this_month' | частка листів акаунта від усіх листів місяця, % (округлено до 6 знаків) |
| 'first_sent_date' | дата першого листа акаунта в місяці |
| 'last_sent_date' | дата останнього листа акаунта в місяці |

## Як це працює
1. **'emails'**: з'єднує таблиці листів, сесій акаунтів і сесій. Дата листа обчислюється як
   дата сесії + 'sent_date' (зміщення в днях), і цей вираз винесений в одне місце.
2. **'monthly'**: групує листи за місяцем і акаунтом. Рахує кількість листів
   та мінімальну й максимальну дату.
3. **Фінальний 'SELECT'**: ділить кількість листів акаунта на загальну кількість листів місяця.
   Для цього використано 'SUM() OVER (PARTITION BY sent_month)', тобто віконна функція
   застосована лише там, де потрібен місячний підсумок.

## Інструменти й прийоми
- Google BigQuery (GoogleSQL)
- CTE, 'JOIN', 'GROUP BY'
- Віконна функція 'SUM() OVER (PARTITION BY ...)'
- 'DATE_TRUNC', 'DATE_ADD', 'MIN' / 'MAX', 'ROUND'
